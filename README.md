# 도트 코리아 1961–1998

박정희 정부부터 김영삼 정부까지, 대한민국 현대사를 사진기를 들고 여행하는 도트 어드벤처 게임.

2026년의 하람은 할아버지 댁 다락방에서 낡은 사진기와 빈 사진첩을 발견한다. 사진기의 정령 '찰칵이'와 함께 1961년으로 떨어진 하람은 시대마다 중요한 순간을 직접 보고 기록해야 다음 시대로 넘어갈 수 있다. 그리고 가는 곳마다 사진기자 '한도윤'을 만나는데…

## 실행

`index.html`을 브라우저로 열면 됩니다. 서버나 빌드가 필요 없고, 폰트까지 포함되어 있어 오프라인에서도 동작합니다.

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Space / Enter / Z | 말 걸기 · 조사 · 대화 넘기기 |
| Shift | 달리기 |
| X / Esc | 메뉴 |
| Tab / P | 사진첩 |
| H | 찰칵이에게 힌트 묻기 |
| M | 소리 켜기/끄기 |

터치 기기에서는 화면 아래(가로 모드는 양옆)에 방향 패드와 A/B 버튼이 나옵니다.

## 구성

| 장 | 시대 | 주요 장면 |
|---|---|---|
| 프롤로그 | 2026 | 할아버지 댁, 사진기와 빈 사진첩 |
| 제1장 | 박정희 정부 (1961–1979) | 5·16, 수출 공단, 경부고속도로, 전태일, 10월 유신, 10·26 |
| 제2장 | 최규하 정부 (1979–1980) | 12·12, 서울의 봄, 5·18 광주, 체육관 선거 |
| 제3장 | 전두환 정부 (1980–1988) | 보도지침, 프로야구, 이산가족찾기, 박종철·이한열, 6월 항쟁, 6·29 |
| 제4장 | 노태우 정부 (1988–1993) | 직선제 투표, 서울 올림픽, 3당 합당, 북방 외교, 유엔 동시 가입 |
| 제5장 | 김영삼 정부 (1993–1998) | 문민정부, 금융 실명제, 성수대교·삼풍, 역사 바로 세우기, 금 모으기 |
| 에필로그 | 2026 | 할아버지에게 사진첩 보여 드리기 |

- 필수 사진 26장, 보너스 사진 13장
- 각 장의 시간의 안개는 그 시대의 핵심 사진을 찍으면 걷힌다
- 장 끝의 '시간의 문'에서 퀴즈 3문제를 맞히면 다음 장으로
- 진행 상황은 브라우저에 자동 저장 (타이틀의 '이어하기')

## 파일 구조

```
index.html          화면 뼈대
css/style.css       UI 스타일
fonts/              Galmuri 픽셀 폰트 (SIL OFL, fonts/OFL.md)
js/audio.js         칩튠 BGM · 효과음 (WebAudio)
js/sprites.js       타일 · 캐릭터 · 소품 도트 그래픽 (모두 코드로 그림)
js/engine.js        맵 · 이동 · 대화 · 사진 · 사진첩 · 저장
js/story_common.js  외모 · 아이템 · 프롤로그 · 에필로그
js/story_ch1~5.js   각 장의 맵 · 인물 · 대사 · 퀴즈
js/main.js          시작
```

## 개발용 주소 옵션

- `index.html?mute=1`: 오디오를 아예 만들지 않음
- `index.html?ch=3`: 제3장부터 바로 시작 (1~5, 0=프롤로그, 6=에필로그)

## 참고

- 실제 역사를 바탕으로 했으며, 하람·한도윤·찰칵이와 일부 시민은 가상의 인물입니다.
- 한 시대의 성과와 어두운 면을 함께 보여 주도록 구성했습니다.
- BGM 7곡과 효과음은 WebAudio로 실시간 생성합니다. 개발 중 오디오 재생 테스트는 하지 않았습니다.
